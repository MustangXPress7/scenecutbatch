**1. New module `src/scenecutbatch/i18n.py`** — follow the module-header convention of
`src/scenecutbatch/media/scanner.py` (one-line docstring, `from __future__ import annotations`
as line 3, stdlib-only imports, UPPER_SNAKE module constant, Google-style one-line-summary
docstrings). Stdlib imports are `locale` and `typing` ONLY — this phase adds no third-party
dependency, so `pyproject.toml` `dependencies` stays exactly as it is
(scenedetect, typer, rich, pyyaml). Required surface (locked by D-35):
  - `SUPPORTED_LANGUAGES = ("en", "es")` module-level constant.
  - `_DEFAULT_LANGUAGE = "es"` (D-35: safe non-English fallback).
  - `STRINGS` flat dict-of-dicts, `{key: {"en": ..., "es": ...}}`, holding EVERY GUI string
    listed in Task 2 of this plan (title, subtitle, signature, language label, form labels,
    option/checkbox labels, button labels, log title, status texts, dialog titles/bodies,
    filedialog titles, the five progress-event log templates). Write the full catalog now —
    a partial catalog would be an architectural shortcut the executor would have to undo.
  - `normalize_language(locale_string) -> str`: strip/case-fold, replace `-` with `_`,
    tolerate `None` and malformed input without raising, return `"en"` only when the string
    starts with `en`, otherwise `_DEFAULT_LANGUAGE`.
  - `detect_language() -> str`: call `locale.getdefaultlocale()` inside `try/except` covering
    `ValueError`, `TypeError` and `AttributeError` (the function is deprecated on 3.11+ and
    removed on later Pythons); on exception, on `None`, or on a non-two-tuple result, fall
    back through `locale.getlocale()` and finally to `_DEFAULT_LANGUAGE`. Return
    `normalize_language(...)` of the best available value.
  - `set_language(lang) -> str`: set the module-level `_current_language` only when `lang` is
    in `SUPPORTED_LANGUAGES`, otherwise set `_DEFAULT_LANGUAGE`; never raise.
  - `current_language() -> str`.
  - `t(key, **kwargs) -> str`: look up the entry, select `_current_language` then fall back to
    `"en"` then to any value; return the bare `key` when the key is unknown. When kwargs are
    passed, apply `.format(**kwargs)` inside `try/except (KeyError, IndexError, ValueError,
    TypeError)` and return the unformatted template on failure. Interpolate ONLY `str`, `int`
    and `float` values — the callers pass clip names, indices, counts and ETAs, never objects.
Translation scope per D-35: GUI strings only. CLI help is NOT added to this catalog
(D-35: CLI stays Spanish-first with an English epilog; full CLI i18n is deferred).

`set_language` mutates module-level state, add a `fresh_i18n` fixture that calls
`set_language("es")` and yields, so tests cannot leak ordering-dependent state.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS locale -> GUI | Untrusted locale string is normalized before use |
| Filesystem -> GUI text | Clip names and paths read from disk flow into translated log lines and dialogs |
| Module state -> views | The mutable `_current_language` and rebuild path drive every widget render |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | `i18n.t()` format interpolation | low | mitigate | `t()` applies `.format(**kwargs)` inside `try/except (KeyError, IndexError, ValueError, TypeError)` and returns the unformatted template on failure; callers pass only `str`/`int`/`float` (clip name, index, total, scenes, eta_sec), never objects or widgets — Task 1 pins this in the module contract and `tests/test_i18n.py` covers the unknown-key path. |
| T-03-02 | Denial of service | `_build_ui()` language-switch rebuild | low | mitigate | `_build_ui()` destroys the previous container before re-packing and the whole rebuild is guarded so a failed render leaves the previous usable window instead of an empty one; the header image reference (`logo_label.image`) is re-assigned on each rebuild so the logo cannot vanish — Task 1, Task 3 item 4. |
| T-03-03 | Elevation of privilege | GUI string catalog / signature source | low | accept | Copy-only change with no code-execution surface: the catalog is a stdlib dict, no `eval`/`exec`, no dynamic import; an attacker would already need write access to the installed package, at which point they control the application anyway. |
| T-03-04 | Information disclosure | Dashboard/config-free, local-only GUI | low | accept | No network, no telemetry, no credentials in scope (locked PROJECT.md constraint). The GUI surfaces only the folder path and clip names the operator already supplied — unchanged from Phase 1. |
| T-03-SC | Tampering | Dependency installs (pip) | high | mitigate | This phase adds no dependency: `i18n.py` imports stdlib `locale`/`typing` only and `pyproject.toml` `dependencies` is left byte-identical. No install task exists, so no package-legitimacy checkpoint is required; the standing gate keeps `T-03-SC` reserved for the phase. |
</threat_model>
